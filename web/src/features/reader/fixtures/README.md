# Original reader fixtures

`original/` contains small original EPUB, PDF, CBZ and uncompressed PalmDB/MOBI files generated by `generate.py`. No external books, images, credentials or licensed media included. PNG contains one pixel; document prose exists only for reader checks.

Regenerate from repository root:

```fish
python3 web/src/features/reader/fixtures/generate.py web/src/features/reader/fixtures/original
```

Generated bytes are checked in so Docker/browser checks need no Python runtime. Hostile fixtures target reserved `.invalid` domain `reader-attacker.invalid`; tests intercept and reject every attempted request. Malformed MOBI references absent image record deliberately. Do not replace these fixtures with user books.
