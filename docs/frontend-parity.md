# Modern frontend action ledger

## Contract and evidence rule

Modern is only supported frontend. Classic remains reachable for legacy access but is not parity gate. This ledger maps Modern route surfaces and visible actions to owning source, permission condition, and test files. Paths are relative to `web/src` unless prefixed with `web/`. Working handlers and passing feature tests establish the supported state; they do not prove every conditional branch or production backend permission. Coverage limits stay explicit rather than being labeled unsupported. `Unsupported` requires visible explanation; absence of control is not automatically an unsupported explanation. Unmapped visible controls are audit findings, not support claims.

Safari/iOS and Cast hardware deferred to #8. Browser Cast code advertises direct-audio-only and hardware unverified (`web/src/features/player/CastControl.tsx:78`).

## Routes and concrete action ownership

Route files live in `web/src/routes/`; routes rendering a feature delegate to the listed feature owner. Permissions below describe visible client gates only; backend authorization remains authoritative. `A` authenticated; `M` root/admin; `upload` is `user.permissions.upload`; `update/delete/download` are per-user permission flags. Route guards and non-action redirects have no mutation action.

## Confirmed coverage limits and unsupported states

- `/library/$library/series` is explicitly routed to `/oops?message=Series not found` by `web/src/routes/library.$library.series.index.tsx:4`; route table does not link it as series index. Record this current Modern routing behavior, not a speculative dead control.
- RSS feed close action has handler but reviewed `features/admin/rss-feeds.test.tsx` covers detail dialog and loading/empty/error/retry, not close mutation. This is an uncovered test assertion, not evidence that action is broken.
- Feature-level test files exist for users, sessions, logs, metadata and settings (`features/admin/{users,sessions,logs,metadata,settings}.test.tsx`). Test existence alone does not establish action outcome coverage; avoid claiming files absent.
- Feature-level mapping does not assert every conditional branch. Unit and browser checks below are execution evidence; a missing focused assertion remains a test gap, not an approved unsupported state.
- Dead failure path fixed: item RSS “Copy feed URL” previously rejected silently when Clipboard API failed. `features/item/ItemActions.tsx` now reports manual-copy fallback beside the absolute URL; `features/item/ItemActions.test.tsx` covers rejected clipboard access.
