# Debug overlay integration boundary

`server/utils/debugHost.js` owns ABS route inventory and fresh database authorization. `server/utils/debugOverlay.js` mounts published package adapter at `/api/debug`, after native JWT middleware. Store opens lazily on first authorized request. Modern admin/root menu enables debug for current identity only; logout start, account change and role loss synchronously disable it. Dashboard navigation uses TanStack links, preserving native player.

Inventory paths are canonical router-relative identities. They never contain `/new` or external router prefix. Dashboard links must use runtime `window.__ABS_WEB_CONFIG__.basePath`; API requests must use existing ABS `api` transport and its refresh behavior. Library/item metadata is queried through projected DB columns, without filesystem or expanded media reads. `getPaths(user)` requires current ABS User model (not just ID), reuses its library/item permission methods, and projects only Book/Podcast `id`, `explicit`, `tags` for item access checks. Restricted admins have no role-based bypass in host-generated inventory. QA notes are shared across all authorized admins/root: package dashboard unions inventory with stored note paths, so another admin's saved path can appear even when absent from current user's inventory. This is not per-item QA isolation; native media/item APIs still enforce actual permissions. Playlists belong to current user; shares must be unexpired and backed by accessible existing media. Nonblank share slugs preserve spaces and punctuation through segment encoding; package path validation must accept these encoded segments. Unsafe dot/sentinel/control paths remain excluded. Inventory failures must surface, not become an empty success.

Every debug endpoint, regardless of method, must run after native JWT middleware and `debugHost.authorize`. Authorization reads current DB `isActive` and `type`; token role and cached client role cannot grant access. Missing identity returns 401, inactive/non-admin returns 403, authorization DB failure returns 503.

Separate store: `Path.join(global.ConfigPath, 'debug-overlay.sqlite')`. Native ABS backups **do not include this file**: BackupManager archives only its ABS database snapshot, item/author metadata and backup details. A stopped-server backup of whole config directory includes debug store; do not claim native ABS backup/restore protects it. Store initialization failure must leave ABS serving normally while debug requests fail closed with visible 503 errors. `Server.stop()` closes store through adapter's synchronous `close()` only after HTTP drain. No trace or log capture.
